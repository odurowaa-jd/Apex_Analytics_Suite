# Apex Analytics Suite: Strategic Financial Monitoring
*Developed by [Jessica Odurowa Danquah] | GNPC Scholar*
*View the Live Suite here:** [https://apex-analytics.infinityfreeapp.com/]

This project serves as a technical demonstration of my transition from **Static Data Handling** to **Scalable Relational Database Management**, specifically designed to showcase readiness for the **MS in Business Analytics** at Wichita State University.

## 📈 Evolution of the Project
### Version 1.0: Static JSON Architecture
- **Focus:** Data Visualization Fundamentals.
- **Logic:** Implemented a PHP parser to extract financial trends from JSON objects.
- **Use Case:** Initial proof-of-concept for loan performance tracking.

### Version 2.0: Dynamic SQL Integration (Production Ready)
- **Focus:** Scalability and Data Persistence.
- **Logic:** Migrated to a **MySQL Relational Database**. Developed a Full-Stack CRUD (Create, Read) pipeline allowing for real-time data entry via a custom Admin Interface.
- **AI Heuristic Engine:** Integrated an algorithmic trend-analysis tool in PHP that evaluates "Risk vs. Growth" status based on real-time database queries.

## 🛠️ Technical Stack
- **Languages:** PHP 8.x, SQL, JavaScript (Chart.js), HTML5, CSS3.
- **Tools:** MySQL (Relational DB), AMPPS (Local Environment).

## 🚀 Why This Matters for Business Analytics
This suite simulates the data pipelines used in the banking sector (Consolidated Bank Ghana). It demonstrates my ability to not only analyze data but to build the **infrastructure** required to manage and visualize it.
